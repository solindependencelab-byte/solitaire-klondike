# Solitaire — Ian development handoff

Windows Klondike Solitaire built with Python 3 and Tkinter.

Features: drag-and-drop stacks, double-click moves, Undo, scoring and move counts, Easy/Classic/Hard modes, Hint suggestions, and a bat emblem on the green felt.

Development: install Python 3 and PyInstaller, then run `python solitaire.py`. Rebuild with `python -m PyInstaller --noconfirm Solitaire.spec`. Keep `card_images` alongside the source. Hints are heuristic, not guaranteed winning moves.
